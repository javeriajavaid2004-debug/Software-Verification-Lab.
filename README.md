# Railway Level-Crossing Control System
## Introduction
This lab focuses on the safety constraints of an Automated Railway Level-Crossing Control System (ARLCCS).
## Objectives
* Identify system safety constraints.
* Convert constraints into logical expressions.
* Identify constraint violations.
* Explain the expected system behavior.
## Tasks
1. Identify Constraints
2. Formalize Constraints
3. Identify Constraint Violations
## System Overview
The system uses train sensors, road barriers, warning lights, audible alarms, and a safety-monitoring unit to control railway crossing traffic.
## Conclusion
Safety constraints help identify unsafe system behavior and support the verification of railway crossing requirements.
